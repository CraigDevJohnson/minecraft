# Security policy

## Reporting a vulnerability

Report suspected security vulnerabilities to [security@craigdevjohnson.com](mailto:security@craigdevjohnson.com).

Include the affected commit or version, a description of the issue and its impact, and reproduction steps or a minimal proof of concept. Omit live credentials and personal data from the report.

Keep vulnerability details private while a fix or mitigation is coordinated with the maintainer. Do not publish sensitive details in public issues or pull requests.
